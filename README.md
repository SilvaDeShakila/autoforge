## 📌 Overview

**AutoForge** is a modern web application developed using **Next.js and TypeScript**.

The project is designed with a focus on:

* ⚡ Fast and modern web development
* 📱 Responsive user interfaces
* 🧩 Reusable and maintainable components
* 🔒 Type-safe development with TypeScript
* 🎨 Clean and consistent UI
* 🚀 Production-ready Next.js architecture

The project serves as a practical implementation of modern frontend development concepts using the **React and Next.js ecosystem**.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* **Node.js 20+**
* **npm**, **yarn**, **pnpm**, or **bun**
* **Git**

### 1. Clone the repository

```bash
git clone https://github.com/SilvaDeShakila/autoforge.git
```

### 2. Navigate to the project

```bash
cd autoforge
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

### 4. Start the development server

```bash
npm run dev
```

Or:

```bash
pnpm dev
```

### 5. Open the application

Visit:

```text
http://localhost:3000
```

## 💻 Development

You can start modifying the application from:
